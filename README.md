Cafe Report
Программа для обработки заказов кофейни за смену и генерации сводного отчёта (количество заказов, общая выручка, средний чек и статистика по официантам).

Дерево проекта
cafe-report/ ├── app/                      # Основной код приложения │   ├── init.py           # Инициализация пакета Python │   ├── main.py               # Точка входа в приложение │   ├── services/             # Модули бизнес-логики и обработки данных │   └── utils/                # Вспомогательные утилиты для расчётов и текста ├── data/                     # Данные проекта (исходные файлы CSV) ├── tests/                    # Модульные тесты для проверки кода ├── docs/                     # Документация проекта ├── .env                      # Файл конфигурации и переменных окружения ├── requirements.txt          # Список зависимостей Python └── README.md                 # Описание проекта
